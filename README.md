# Deepfake-Detection-Comparative-Analysis
A Fake Busters comparative study evaluating 5 models: SOA (ViT-CLIP), ConvNeXt V2, Autoencoders, MesoInception-4, and SVM Fusion. Analyzing 360,000+ images from FF++ &amp; Celeb-DF to bridge the deepfake "generalization gap". Full technical report included.
